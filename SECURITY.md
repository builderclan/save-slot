# Security Policy

## Supported Versions

Security updates are actively applied to the following release branches:

| Version | Supported          |
| :---    | :---:              |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

The SaveSlot team takes security vulnerabilities seriously. If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** file a public GitHub issue for security vulnerabilities.
2. Please send an email to **<security@campus.edu>** (or open a private GitHub Security Advisory) with:
   - A description of the vulnerability and its potential impact.
   - Steps to reproduce or a proof of concept (PoC).
   - Your name/handle for public acknowledgement (if desired).
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for triage and remediation.
4. Once a fix is verified and released, we will publicly credit the finder in our release notes.
